核心特性

为 Agent 原生开发而生

从上下文管理到 Provider 桥接，Agents GUI 让你专注于编码，而非配置。

🔄

多 Agent 一键切换

在 Claude、Codex、Gemini 等 Agent 之间无缝切换，每个 Provider 拥有独立的模型、模式和权限配置。

🧠

上下文感知提示词

自动附加工作区元数据、当前文件内容、选中区域和诊断信息，让 AI 始终拥有完整项目上下文。

⚙️

CLI 配置管理

预配置的 CLI 配置文件处理命令解析、参数构建和输入模式。支持自定义 API Provider。

🔌

Provider 扩展桥接

从侧边栏直接启动配套 VS Code 扩展（OpenCode、Codex、Claude Code、Gemini CLI）。

📊

精确 Token 计数

内置 Anthropic 精确 Token 计数器和基于 tiktoken 的 OpenAI 计数器，按 Provider 智能切换。

🌐

中英文双语支持

扩展 UI 和 Webview 界面均内置英文和简体中文本地化，全球开发者无障碍使用。
